# Daemon Reborn placeholder sprite asset pack

Original, deliberately simple 64×64 robot. Four RGBA PNG frames, no background.

## Contents

- `frames/placeholder_0001.png` through `placeholder_0004.png`: actual 64×64 RGBA PNG files.
- `placeholder_spritesheet.png`: 256×64 RGBA PNG strip, four frames left-to-right.
- `placeholder.pixelorama.json`: pre-export Pixelorama **project JSON** companion. Frame `duration` is a multiplier of `1/fps`, not milliseconds. Tags are **1-based inclusive**.
- `atlas.json`: native Pixelorama v1.2.4-stable JSON export, normalized by the Daemon export pipeline.
- `atlas.png`: native Pixelorama v1.2.4-stable spritesheet export.
- `manifest.json`: canonical validated runtime manifest generated by the Daemon export pipeline.
- `native-provenance.json`: pipeline provenance for the native export.
- `placeholder.atlas.json`: independent atlas description with frame rectangles and **milliseconds**, and **0-based inclusive** tag ranges.
- `placeholder.pxo`: constructed Pixelorama ZIP-format project with editable raw RGBA frame cels; opened and exported successfully by Pixelorama v1.2.4-stable.
- `PROVENANCE.md`: exact creation/license/attribution and verification scope.
- `SHA256SUMS.txt`: checksums of all deliverable source and native-export files except the checksum file itself.

## Animation specification

| Frame | File | Pixelorama tag | Duration multiplier | Duration |
|---|---|---|---:|---:|
| 1 | `placeholder_0001.png` | idle | 7 | 700 ms |
| 2 | `placeholder_0002.png` | idle | 7 | 700 ms |
| 3 | `placeholder_0003.png` | blink | 1 | 100 ms |
| 4 | `placeholder_0004.png` | blink | 1 | 100 ms |

Canvas: 64×64. FPS: 10. Frame count: 4. Every frame is covered exactly once by tags (`idle`: 1–2; `blink`: 3–4).

## Approval / Pixelorama verification

The original frames were generated procedurally, then the editable project was
opened and exported by Pixelorama v1.2.4-stable. The native export and owner
approval are recorded in Linear ORC-185. The verified round-trip produced the
following outputs in this directory:

1. `atlas.png` — 256×64 RGBA spritesheet.
2. `atlas.json` — native JSON with four frames and complete `idle`/`blink` coverage.
3. `manifest.json` — validated canonical manifest with 700/700/100/100 ms durations.
4. `native-provenance.json` — source hash, license, and editor version.
5. `SHA256SUMS.txt` — checksums for the source and native-export files, excluding the checksum file itself.
